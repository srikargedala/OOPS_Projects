# Python OOP Projects

A collection of Python projects developed to practice and demonstrate Object-Oriented Programming (OOP) concepts.

## Projects

### 1. Student Management System
A system for managing student information, including adding, updating, deleting, and viewing student records.

**Concepts used:**
- Classes & Objects
- Encapsulation
- Methods
- Lists
- Exception Handling

### 2. Library Management System
A system for managing books, members, borrowing, and returning books.

**Concepts used:**
- Classes & Objects
- Encapsulation
- Inheritance
- Polymorphism
- Exception Handling

### 3. E-Commerce System
A simple e-commerce system for managing products, customers, shopping carts, and orders.

**Concepts used:**
- Classes & Objects
- Encapsulation
- Composition
- Inheritance
- Polymorphism

### 4. Vehicle Rental System
A system for managing vehicles, customers, rentals, and vehicle availability.

**Concepts used:**
- Classes & Objects
- Inheritance
- Polymorphism
- Encapsulation
- Exception Handling

### 5. Hospital Appointment System
A system for managing doctors, patients, and appointments.

**Concepts used:**
- Classes & Objects
- Encapsulation
- Association
- Composition
- Exception Handling

### 6. Task Management System
A system for creating, updating, assigning, and tracking tasks.

**Concepts used:**
- Classes & Objects
- Encapsulation
- Inheritance
- Polymorphism
- Exception Handling

### 7. File Organizer
A Python utility that organizes files into folders based on their file types.

**Concepts used:**
- Classes & Objects
- Encapsulation
- File Handling
- Exception Handling
- `os`
- `shutil`

## OOP Concepts Practiced

Throughout these projects, the following Python OOP concepts are practiced:

- Classes and Objects
- Constructors
- Instance and Class Variables
- Instance, Class and Static Methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Association
- Aggregation
- Composition
- Method Overriding
- Dunder Methods
- Exception Handling

## Technologies

- Python

- File Handling
- Exception Handling
- Standard Python Libraries

The purpose of this repository is to strengthen Python programming and Object-Oriented Programming skills through practical projects rather than only theoretical learning.
